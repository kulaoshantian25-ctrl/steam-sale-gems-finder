# 🎮 Steam Sale Gems Finder

Steamのセール対象の中から「70%以上の大幅割引」「多数のレビュー」「圧倒的高評価」の作品をピックアップし、自分のウィッシュリストや所持ゲームを除外して一覧できる個人用Webツールです。

---

## 🚀 使い方

### 起動方法
1. [start.bat](file:///C:/Users/d87lk/.gemini/antigravity/scratch/steam-sale-finder/start.bat) をダブルクリックするだけで自動起動し、ブラウザ（`http://localhost:3456`）が開きます。
2. （またはターミナルで `node server.js` を実行）

---

## ✨ 主な機能

- **70%以上OFFの厳選表示**: デフォルトで70%以上OFFのセール品のみを抽出（スライダーで30%〜90%まで自由に変更可能）
- **高評価 ＆ レビュー多数でソート**:
  - 最低レビュー数（デフォルト 1,000件以上）
  - 最低好評率（デフォルト 85%以上、非常に好評〜圧倒的に好評）
  - 並び順：レビュー総数順、好評割合順、割引率順、セール価格順
- **ウィッシュリスト ＆ 所持ゲームの除外**:
  - **方法1 (超かんたん)**: Steamにログインしたブラウザで [userdata](https://store.steampowered.com/dynamicstore/userdata/) を開いてコピー＆ペーストするだけで、ウィッシュリストと所持ゲームを瞬時に除外リストへ一括登録
  - **方法2**: SteamID64（公開設定）またはAPI Keyを入力して同期
  - **方法3**: 各ゲームカードの「除外」ボタンを押すだけで即座に非表示（ブラウザに記憶）
- **1クリックでSteamストアへ**: 気になった作品はそのままSteamストアページに遷移して購入・チェック可能
- **ローカルキャッシュ**: 取得したセール情報は1時間キャッシュされ、2回目以降は超高速に表示
